# Research: Wix + Envato + SEO Standards 2026

## Wix Template System (900+ templates)

### Categories (15+)
Restaurant, E-commerce, Beauty/Spa, Tech/SaaS, Health, Education, Real Estate, Fitness, Portfolio, Business, Blog, Events, Travel, NGO, Personal/CV

### Key Features mỗi template có
- Mobile-responsive across devices
- Fast loading speeds
- Built-in SEO optimization
- Fully customizable sections
- Industry-specific blocks (booking, menu, scheduling, etc.)

### Pattern — mỗi ngành có blocks riêng
- Restaurant: interactive menus, reservation, social media feed
- Beauty: appointment scheduling, treatment packages
- Tech: interactive animations, video demo, pricing comparison
- Health: doctor profiles, patient booking, insurance info
- Fitness: class schedules, membership, workout plans, video tutorials

## Landing Page Anatomy (Shopify/Unbounce 2026)

### Section Order (conversion-optimized)
1. Hero: headline + value prop + CTA + visual (within 600px)
2. Trust bar: press logos, ratings
3. Features/benefits (scannable)
4. Social proof (testimonials)
5. Secondary CTA
6. Additional details
7. Final conversion opportunity

### Above-the-Fold (600px) MUST HAVE
- Bold, problem-focused headline
- Clear value proposition
- Primary CTA button (high contrast)
- Supporting visual
- Trust signal (rating/customer count)

### CTA Strategy
- 1 prominent CTA above fold
- Secondary CTAs after features, testimonials
- Button hierarchy: dark for primary, light for secondary
- Contextual to preceding content

## SEO Checklist 2026 (Technical)

### Meta Tags
- title (50-60 chars), description (150-160 chars)
- viewport, canonical, hreflang

### Heading Hierarchy
- 1 H1 per page, H1→H2→H3 no skipping

### Structured Data (JSON-LD)
- Homepage: Organization + WebSite + SearchAction
- Blog: Article/BlogPosting (author, date)
- Services: Service + Offer
- FAQ: FAQPage
- Contact: LocalBusiness
- Products: Product + Review + AggregateRating
- All: BreadcrumbList

### Core Web Vitals
- LCP < 2.5s, INP < 200ms, CLS < 0.1, TTFB < 800ms

### Images
- WebP/AVIF, width/height attributes, lazy loading, srcset, alt text

### Mobile
- Min tap target 48×48px, min font 16px, test real devices

## Animations (2026 standard)
- Fade-in on scroll (0.4-0.6s)
- Slide-up for cards (0.3-0.5s)
- Stagger for lists (0.1s delay)
- Counter animation for stats (1.5-2s)
- Hover scale for cards (0.2-0.3s)
- Parallax for hero backgrounds
- MUST respect prefers-reduced-motion

## Key Visual Patterns

### Hero Sections
- **Full-bleed image** with overlay text (Brancy, Zakas)
- **Split layout** — text left, image right (Parlo, NIXX)
- **Carousel/slider** — auto-sliding banners (BeShop, EcoShop)
- **Video background** (Exzo)

### Section Ordering (typical homepage)
1. Navigation (sticky)
2. Hero (carousel or static)
3. Category/collections grid
4. Featured products/services (cards)
5. Banner/CTA mid-page
6. Testimonials
7. Blog preview (3 posts)
8. Newsletter signup
9. Footer (mega)

### About Page Pattern
1. Mini hero (breadcrumb + title)
2. Story section (text + image split)
3. Timeline/milestones
4. Team grid (3-4 members)
5. Values/philosophy
6. CTA

## Old ECH v1 Schema (c101.json / dn001.json)
- Component-based: banner with images collection (up to 10)
- Each image slide: header, subheader, button (default + hover states), alignment
- Bilingual: EN + MS (label + label_ms)
- Color picker with 15 predefined palette colors
- Size options: hero banner vs small banner
- Animation: manual-sliding vs auto-sliding + timing
- Image upload: picker from media library OR direct upload

## Takeaways for Template Blueprints
1. **Page variety matters** — most templates have 5-7 distinct pages, not just homepage
2. **Section ordering varies by industry** — eCommerce puts products early, beauty puts gallery early
3. **Mid-page CTAs** — banners/promotional sections break up content flow
4. **Blog preview on homepage** — common pattern, adds freshness
5. **Consistent design language** — same colors/fonts/spacing across all pages
6. **Category-specific sections** — menu for F&B, products for ecom, gallery for beauty

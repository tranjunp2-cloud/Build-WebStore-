## Key Findings

### Accessibility dim = best v1.2 signal (avg 6.3)

Drills into:
- `alt-text-coverage-80`: fail most templates (harness uses SVG placeholders — no alt)
- `heading-order-no-skip`: some templates có logo-cloud trước hero (violates H1-first)
- `theme-color-contrast`: most pass (themes default WCAG AA)
- `nav-aria-label`: fail many (no ariaLabel field in navigation data)
- `focus-indicator-defined`: fail all (theme không define focusStyle)

Actionable insights:
1. Add `alt` field to content library image items
2. Review block order — ensure hero always before section blocks với headline
3. Add `focusStyle` token to theme schema

### Category DNA dim (avg 9.3)

Most templates match category expectations từ content library. Fails:
- Some ecommerce missing `product-quick-view`
- Some events missing `booking-widget`

### Remaining ceilings (future v1.3+)

- **Spacing 10.0**: `spacingRhythmTokenOnly` returns pass when block has no explicit spacing values (most theme-driven templates). Need different signal.
- **Conversion 9.4**: `heroCtaVariety` easy pass (different variants almost always)
- **Content 9.2**: `contentDepth500` met bởi most templates

## Why v1.2 Didn't Hit 5.8-6.5 Target

Target missed (8.37 vs predicted 5.8-6.5) vì:

1. **Templates structurally strong** — composer đã follow WEBSITE_TEMPLATE_STANDARDS tightly, nhiều criteria pass by design
2. **Accessibility dim new** but có 2 criteria pass easily (color contrast from theme, heading order logic permissive)
3. **Category DNA permissive** — composer generates expected blocks per category by construction

## Recommended Next Steps

Instead of chasing lower avg (diminishing returns), focus on:

1. **Accessibility push**: add `alt`, `ariaLabel`, `focusStyle` fields → immediate quality win, a11y score 6.3 → 9.0
2. **Content library expansion**: avatars + ratings trong testimonials → social-proof 7.5 → 9.0
3. **Spacing rubric redesign v1.3**: measure actual rendered spacing (Playwright scanning) instead of data-level — catches what v1.2 misses

## Unresolved

1. Cross-fixture uniqueness (deferred v1.3) — detect copy-paste headlines
2. Runtime Lighthouse checks — performance/a11y/SEO from rendered HTML
3. Category-color enforcement (different dimension idea) — restaurant=warm, tech=cool, etc.

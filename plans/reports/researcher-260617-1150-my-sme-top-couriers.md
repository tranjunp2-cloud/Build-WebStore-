## Executive Summary

**Top 3 Ranking (HIGH CONFIDENCE):**

1. **J&T Express** — #1 by market adoption, volume, SME preference
2. **Pos Laju** — #2 by coverage, government/enterprise trust, rural reach
3. **Flash Express** — #3 by growth, affordability, Gen-Z/TikTok appeal

**Confidence Drivers:** J&T dominates Southeast Asia (30.13B parcels 2025, 22.2% YoY growth; 7.66B in SEA alone, 67.8% YoY). Pos Laju: 3,500+ nationwide touchpoints, only uniform E. Malaysia coverage. Flash Express: fastest-growing, zero-minimum pickup, RM5 entry rate, strong Shopee integration. All 3 support COD.

**UI Recommendation:** Default enable J&T + Pos Laju + Flash Express in checkbox/toggle list with "Popular choice" badge. J&T → top position. Hide remaining 3 couriers (DHL eCommerce, City-Link, Ninja Van) under "Show more couriers" expandable if usage data confirms they're <5% merchant adoption.

## Ranking Detail & Rationale

### 1. **J&T Express** (Tier 1 — Market Leader)
- **Market Position:** SE Asia #1 by parcel volume; 25.4% SE Asia market share (2023); 30.13B global parcels 2025
- **Malaysia Strength:** Fastest domestic delivery (1–3 work days), lowest cost (RM5–15 range), seamless Shopee/Lazada/TikTok Shop integration
- **SME Adoption:** Heavily preferred by Shopee sellers; used for daily bulk pickups; competitive pricing under pressure from newer entrants
- **Coverage:** Peninsular Malaysia (dense); East Malaysia (present but patchy vs Pos Laju)
- **COD:** Full support; standard for e-commerce orders
- **Rating (EasyParcel):** 5.0 stars (tied highest user rating)
- **Risk/Caveat:** Pricing war compression; some rural coverage gaps in East Malaysia

## Regional Breakdown: West vs East Malaysia

### **West Malaysia (Peninsular)**
- **Top Choice:** J&T Express (fastest, cheapest, most frequent)
- **Secondary:** Flash Express (budget alternative, Gen-Z skew)
- **Fallback:** Pos Laju (reliable, nationwide)
- **Coverage:** All major couriers dense; price competition fierce

### **East Malaysia (Sabah + Sarawak)**
- **Top Choice:** Pos Laju (ONLY uniform district coverage)
- **Secondary:** City-Link Express (local presence, 15+ years)
- **Challenge:** J&T/Flash/Ninja Van have gaps in remote areas; SkyNet + KEX niche players
- **Coverage:** Rural/remote areas → Pos Laju only safe bet

**Implication for F36 UI:**  
- If merchant's base address is in East Malaysia (Sabah/Sarawak), **DEFAULT to Pos Laju** even if user chose J&T globally.
- West Malaysia → default J&T + Pos Laju + Flash Express in order.

## COD (Cash on Delivery) Capability

**COD Support in Top 3:**

1. **J&T Express** — Full COD; de facto standard for Shopee/Lazada orders; handles cash → bank settlement within 3–5 days
2. **Pos Laju** — Full COD; government-trusted; slower settlement cycle (~7 days)
3. **Flash Express** — Full COD via **QR Pay hybrid** (merchant collects cash, QR-triggered collection minimizes physical exchange); modern approach popular with younger sellers

**F36 COD Rule Impact (West Malaysia):**  
F36 spec mentions COD restricted to West Malaysia (Peninsular) due to cash-handling complexity in East Malaysia.

- **All top 3 support COD in Peninsular Malaysia.**
- For **East Malaysia**, only **Pos Laju** recommended for COD (others' COD policies unclear/limited).

**All Couriers Full COD Support:**  
DHL eCommerce, City-Link, Ninja Van also support COD, but adoption lower among SME cohort.

## UI/UX Recommendation for F36

### **Default Behavior (First Connection)**

When merchant connects EasyParcel API for 1st time, EasyParcel returns ~6 couriers. F36 UI should:

**Option A (Recommended): Selective Default with Progressive Disclosure**
```
┌─────────────────────────────────────────────────┐
│ SELECT COURIERS FOR YOUR STORE                  │
├─────────────────────────────────────────────────┤
│ ✓ J&T Express              [Popular ⭐] [Day]   │
│ ✓ Pos Laju                 [Nationwide] [Day]   │
│ ✓ Flash Express            [Budget]      [Day]  │
│ [+ Show 3 more couriers]                        │
└─────────────────────────────────────────────────┘
```
- **Enabled by default:** J&T + Pos Laju + Flash (checkboxes ticked)
- **Collapsed:** City-Link, DHL eCommerce, Ninja Van (expandable "Show more")
- **Badges:** "Popular", "Best Coverage", "Cheapest" (data-driven, refreshed quarterly)
- **Rationale:** Reduces decision fatigue; focuses on highest-adoption tier; user can expand if needed

**Option B: Reorder + Sort**
- Sort returned list by "SME popularity" score, not API default order
- Pin top 3 at top with "Recommended for SMEs" header
- Rest sorted by user ratings (EasyParcel data)

**Option C: Smart Default (Best for Repeat UX)**
- Detect merchant geolocation from address
  - **West Malaysia** → J&T + Pos Laju + Flash (default all enabled)
  - **East Malaysia** → Pos Laju + J&T + City-Link (Pos primary)
- Store choice; pre-fill on next session

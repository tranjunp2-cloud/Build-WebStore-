# Mapping migrate 9 legacy templates sang Prime Web v2

## Mục tiêu và nguyên tắc

Tài liệu này là hợp đồng adaptation cho 9 template trong [`static-prototypes`](./static-prototypes/README.md). Giai đoạn hiện tại chỉ cập nhật static HTML để review UI; **chưa tạo `TemplatePreset`, chưa seed Payload và chưa đưa vào template library**. Mỗi section legacy phải được biểu diễn bằng block đã đăng ký trong [`src/blocks/registry.ts`](../../../src/blocks/registry.ts) hoặc storefront infrastructure đã tồn tại.

- Static HTML chỉ mô phỏng cấu trúc/behavior để review, không có nghĩa React block đã được import hoặc tích hợp runtime.
- Không import Vue component, CSS bundle hoặc JavaScript runtime cũ.
- Không tạo block/component mới để đạt pixel parity.
- Không dùng `custom-html` để bọc lại section cũ.
- Chấp nhận đổi layout khi không có block tương đương; ưu tiên đúng data flow và hành vi commerce.
- `navigation`, `footer`, `cartWidget` là global. Cart drawer, checkout, product detail và order tracking là storefront infrastructure, không phải page block; các HTML tương ứng vẫn thuộc scope hiện tại dưới dạng static mirror.
- `LoadingComponent`, `GlobalLoading`, `TemplateLayout` và wrapper thuần layout bị bỏ hoàn toàn.

Nguồn kiểm chứng: `manifest.json` và HTML trong từng thư mục static; registry/config/renderer trong `src/blocks`; storefront components hiện có.

## Baseline coverage bắt buộc cho homepage

Sau khi map toàn bộ section nhìn thấy trong source, dev phải đối chiếu thêm sáu capability của legacy homepage builder. Source export thiếu capability nào thì bổ sung UI bằng block Prime Web v2 đã đăng ký tương đương; không được bỏ qua và không được tạo component mới. Trong mapping riêng của template phải ghi rõ `source replacement` hay `coverage addition`.

| Capability legacy | Block Prime Web v2 dùng thay thế                                          |
| ----------------- | ------------------------------------------------------------------------- |
| Hero banner       | `HeroBlock` / `hero`                                                      |
| Small banner      | `CTABlock` / `cta`; chỉ dùng `CarouselBlock` khi có nhiều promo thật      |
| Category Listing  | `CarouselBlock/cards`, `GalleryBlock/grid` hoặc `PortfolioGridBlock/grid` |
| Product Listing   | `ProductsGridBlock` hoặc `ProductsFeaturedBlock`                          |
| Article Listing   | `BlogListBlock` / `blog-list`                                             |
| Rich Text         | `AboutBlock` / `about`                                                    |

Đây là checklist về vai trò nội dung, không bắt buộc thứ tự cố định. Một section hiện hữu có thể đáp ứng một capability nếu semantics phù hợp. Coverage addition phải dùng nội dung lấy từ source hoặc đã được duyệt, không tự tạo claim kinh doanh.

## Cách dev sử dụng tài liệu

Mỗi static section phải có ba annotation: `data-block-type`, `data-block-variant`, `data-mapping-status`. Dev đọc theo thứ tự:

1. Tìm template trong bảng file bên dưới.
2. Đối chiếu section legacy với recipe của template.
3. Mở component/config v2 từ bảng mapping dùng chung.
4. Nếu trạng thái là `approximation`, giữ đúng component v2 và chấp nhận khác biệt đã note; không tạo component mới.
5. Nếu là `removed`, không migrate markup/behavior đó. Nếu là `runtime`, static page hiện tại phải mirror UI anatomy của storefront source; production sau này dùng infrastructure thật, không mang state/business logic demo sang.

## Tham chiếu route cho giai đoạn production sau này

Các route dưới đây thuộc phạm vi review static hiện tại dưới dạng UI mirror, nhưng vẫn không được seed thành page block hoặc mang business logic demo sang production. Static HTML phải bám anatomy của storefront runtime được chỉ định; production sau này tiếp tục dùng route/runtime thật.

| Legacy route                            | Kết quả v2                                                                             | Quyết định                                                                                                         |
| --------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `/`                                     | Home trong `templatePages`                                                             | Recipe riêng theo template.                                                                                        |
| `/products`                             | `navigation → hero/minimal → products-grid → footer`                                   | Filter/sort/pagination nằm trong grid.                                                                             |
| `/articles`                             | Chuẩn hóa `/blog`: `navigation → hero/minimal → blog-list → newsletter → cta → footer` | Detail dùng `/blog/[blogSlug]`; redirect legacy là việc cutover ngoài preset.                                      |
| `/about-us`                             | Chuẩn hóa `/about`                                                                     | Dùng `about` và block bổ trợ hiện có; không bịa timeline/stats.                                                    |
| `/contact`                              | `navigation → contact/split → faq (nếu có dữ liệu) → footer`                           | Không thêm map nếu chưa xác thực địa chỉ/tọa độ.                                                                   |
| `/cart`, `/checkout`, `/order-tracking` | Static mirror, không seed thành block                                                  | Cart mirror không state/redirect; checkout mirror runtime anatomy; order-tracking forward CTA chuẩn hóa `/orders`. |
| Product/article detail                  | Static mirror, không seed thành block                                                  | Mirror dynamic route anatomy hiện có; production dùng dynamic routes.                                              |

## Recipe migration theo template

### 1. EcoGarden — PA101 (`ecommerce`)

Static review: [`pa101/index.html`](./static-prototypes/pa101/index.html). Bỏ: legacy slider plugin, hashed component CSS, loading wrappers; cart chỉ là demo của `CartDrawer`/`cartStore` runtime.

Static adaptation status: **`needs-ui-review` — đã dựng lại UI theo renderer v2 (2026-08-18)**, khớp với [`pa101/manifest.json`](./static-prototypes/pa101/manifest.json). HTML là static visual contract, không import React runtime, nhưng DOM/CSS/behavior đã được dựng lại theo các renderer và variant thực tế dưới đây. Không còn dùng visual structure của component legacy làm nguồn chuẩn. Trong PA101, `exact` nghĩa là bám visual anatomy/variant của renderer; không có nghĩa static HTML đã có Next.js, Payload, store hoặc analytics runtime.

Toàn bộ nội dung review trên Home được pre-render trong HTML: 6 content sections, 8 product cards, 3 blog cards và 3 category slides vẫn hiển thị khi JavaScript bị tắt. JavaScript chỉ progressive-enhance slideshow, carousel controls, mobile menu và cart demo; không được dùng để tạo section/card thay cho HTML.

Home: `navigation(centered) → hero(slideshow) → about(centered-large) → cta(image-bg) → products-grid(grid-3, limit 8) → blog-list(cards, 3) → carousel(cards: categories) → footer(dark-gradient)`; global floating `cartWidget` mở runtime `CartDrawer`.

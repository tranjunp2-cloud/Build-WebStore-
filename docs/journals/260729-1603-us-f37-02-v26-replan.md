# US-F37-02 v2.6 re-plan

## Context

PR #1677 merged the PRD v2.6 contract after the original US-F37-02 plan had already progressed against Schema 40. The obsolete local plan was cancelled during review and later removed during cleanup; the replacement plan restarts from the current documentation and keeps implementation out of this session.

## What happened

- Reframed the story to FR-04..11 with an exact Schema score of 35: LocalBusiness 10, subtype 4, opening hours 5, geo 4, telephone 3, URL 3, price range 3, and Organization 3.
- Removed FAQ from the score contract and kept overall `20/35/15/30`, score API wiring, and Dashboard behavior under US-F37-04.
- Designed `schemaSubtype` as a complete vertical slice: versioned category-to-subtype mapping, Payload field, additive SQL migration, effective-state server validation, dependent Editor control, safe JSON-LD emission, and canonical scoring evidence.
- Added Phase 00 because issue #1310 and the story document still describe the stale contract. Product work cannot pass review until those sources, QA IDs, the mapping annex, and fixture ownership are synchronized.
- Treated open PR #1708 as a semantic completion gate. Its accepted save mutex, rollback, sparse-patch validation, nested compatibility, and Business 20 ownership must survive reconciliation.

## Red-team corrections

- Cancelled the old Schema-40 plan during review, then removed its local artifact during cleanup so automation cannot resume it.
- Put the read-only storefront E2E in `tests/` under a narrow unauthenticated Playwright matcher, with a reproducible fixture manifest and explicit preflight behavior.
- Required validation against `originalDoc + incoming patch` across all Payload write paths, plus atomic category/subtype saves and stale-response protection.
- Bound generation and scoring to one canonical artifact from one immutable site snapshot; weak or duplicate legacy nodes cannot combine into a false score.
- Added deterministic failure predicates and raw-HTML serializer/XSS evidence, not DOM-only assertions.

## Decisions

- PRD v2.6 is the technical target, but stale issue/story text remains a Phase 00 P0 gate.
- Empty or incompatible subtype emits generic `LocalBusiness` and earns 0/4 subtype points.
- The scorer stays pure and tops out at 35; #1312 owns production aggregation and display.
- No product code was changed during this re-plan.
